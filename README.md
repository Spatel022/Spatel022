# Samir AI E-commerce Hub

A personal e-commerce workspace MVP for marketplace listing work.

## Included
- Dashboard
- AI-style listing generator UI
- Profit and ROI calculator
- Customer reply helper
- SEO keyword helper
- Responsive design

## Deploy
This project is now at the repository root, so Render Static Site can use the repository root directly. No Root Directory is required.

## Important
The listing generator currently works as a browser-only MVP. For true generative AI, connect a secure backend/API. Never expose an OpenAI API key in frontend JavaScript.
