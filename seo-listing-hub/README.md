# SEO Listing Hub

Personal browser-based e-commerce SEO tool.

## Run
No npm, Node.js, terminal command, or server is required.
Open index.html in Chrome or Edge. VS Code Live Server is optional.

## Features
- SEO title generator with marketplace character limits
- SEO description
- 5 bullet points
- Search keyword generation
- Keyword analysis
- Existing listing audit
- Copy individual results / Copy All
- Responsive UI
- No API key required

This version runs locally in the browser and uses rule-based generation.
